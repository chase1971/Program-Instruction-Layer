2 Two tools, two loaders

You use Cursor mainly and Claude Code sometimes. They don't read the same files.

File type Cursor Claude Code
AGENTS.md (Programs root) Yes No — unless imported
CLAUDE.md (Programs root) Yes Yes
.cursor/rules/*.mdc Yes (glob-scoped) Never
App CLAUDE.md Sometimes Yes
ESLint / pre-commit hooks Always (on save/commit) Always (on save/commit)

Fix at root: CLAUDE.md is now just @AGENTS.md — one copy of the rules, both tools see it. Each app's CLAUDE.md stays as a short index naming its rules (Claude Code can't see .mdc files).

3 The capture ladder

When something breaks and we fix it, the lesson gets pushed as high as it can go. Higher = more reliable. Prose at the bottom; code enforcement at the top.

Golden rule: When a lesson moves up the ladder, delete the lower copy. That's how persisted-state.mdc and 600+ lines of file-size docs survived as ghosts — prose never got removed after lint shipped.

6 One sentence to remember

Enforce in code first.
Contract in globs second.
Always-on only for safety.
Docs are the backup — not the primary brain.

Starting a new app?

Say "initialize a new app" → scaffold gets AGENTS.md pattern, app CLAUDE.md index, and glob rules as you define vocabulary (scroll bars, dwell, modals). Copy Math App Studio's shape, not its content.

Fixed a nasty bug?

Walk the capture ladder. Pearson cookies went to Level 1 (code invariant) + Level 3 (pearson-session-contract.mdc) + startup warning log.
