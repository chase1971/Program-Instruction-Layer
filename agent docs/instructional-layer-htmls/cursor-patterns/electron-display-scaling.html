cursor-patterns/electron-per-monitor-display-scaling.md

Spec for every Electron app's title-bar "Display" button and slider scaling. 267 lines. As of 2026-08-07, split into a required half (manual Display button/slider) and an optional half (automatic per-monitor memory).

Optionalper-monitor auto-memory
2026-08-07 policy change: Chase reported that in Macro App — the exemplar for the per-monitor half of this spec — moving the window between his TV and secondary monitor doesn't restore each monitor's own remembered scale the way it's supposed to. He wasn't getting the one thing that half of the feature is for (tune each monitor once, never re-adjust). Rather than debug it, he chose to downgrade: the manual Display button + slider stays required for every Electron app (it fixes a real, confirmed clipping bug), but automatic per-monitor detection/memory (Phase 3 in the checklist below) is now optional — build it only if he specifically asks. Physically different monitors can't be made to "look the same" through zoom alone regardless of whether the memory works, which he'd already reasoned through himself.
