Student portal — instructor unlock

Firefox remembers one student code per site. These tools let you preview any student link without clearing cookies — sign in as CHASE1 once, then hop between students.

One-time setup — save a bookmark

Drag one of these to your Firefox bookmarks bar (or right‑click → Bookmark Link).

Unlock this browser (sign in CHASE1) Switch student (unlock + reload link)

Every time you want a different student

  1. Open the student’s personal portal link (or paste it in the address bar).
  2. If you see “someone else’s link”, click Switch student in your bookmarks bar.
  3. Or click Unlock, then open the student link again.

First time on this Firefox profile

  1. Click Unlock this browser — it opens CHASE1 and marks this Firefox as yours.
  2. After that, any student link should open without the block.
