Macro App Docs Review

Second app in the School Scrips conformance-pass series, run one app at a time per agent docs/APP_CONFORMANCE_PASS.md — same method as App Dashboard. All 50 markdown files under School Scrips/Macro App/ checked against the live code they describe (three parallel passes, each opening the real source rather than trusting a doc's own prose). This is the Phase 1 report — no files have been changed.

The shape of it, in short: Macro App's instruction layer is large and mostly healthy — 38 of 50 files checked out accurate against current code, including every Pearson/grades/roster automation doc (CLI subcommands, function names, file paths all matched exactly) and the enforcement layer (husky pre-commit: file-size check, secret scan, lint-staged — all wired and tracked). The drift that exists is concentrated in three places: the ADR set (2 of 4 written ADRs have stale claims, and a 5th was never written despite the component it covers already being live), two audits that describe a problem as still-open when the code was already fixed since, and one high-traffic doc (EMBEDDED_BROWSER_AND_MODALS.md) that Chase's own keyword table routes debugging questions to, which has drifted on several concrete file paths and constant values.
