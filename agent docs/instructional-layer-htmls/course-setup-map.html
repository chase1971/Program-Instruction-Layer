How Course Setup Actually Works

A plain-language guide to what you decide during Setup Courses, what those decisions connect to, and which Macro App tabs need which piece later in the semester. Written for someone who has never seen the config files.

Setup is really two separate jobs. Most people mix them up because they happen in the same wizard. Keeping them straight is the whole game.

① Who you teach & when

Which D2L sections are yours, when class meets, and which My Calendar workbook tab goes with each section. No student names.

Powers Pearson, First Day Handout, Manage Dates, and every course dropdown.

② Your gradebook workspace

A folder per course with a roster CSV downloaded from D2L — names, emails, org IDs. Optional during setup; you can add it later from the Gradebook tab.

Powers Gradebook, Assignment Assistant, and Makeup Exam only.

The Setup wizard — what each step is really doing

After sign-in
Pick which D2L sections you teach

The app scans D2L and shows your course list. You check the sections for this term and can rename them to something you'll recognize all semester (e.g. shorten "MATH-1314 4201 6W2" to "M1314 Summer II").

What you're deciding: the master list of courses Macro App knows about. This is not assigning students or calendars yet — it's just "these shells exist and belong to me."

Who reads this later
  • Every tab with a course picker (Gradebook, Pearson, First Day Handout, Manage Dates, …)
  • Folder names if you export rosters
For each new section
Tell the app your class schedule

For each course you haven't set up before, you answer: online or in-person, which term (Fall, Spring, Summer I, Summer II), and if in-person — meeting days (Mon/Wed, Tue/Thu, Mon–Thu) plus class start and end time.

What you're deciding: when your class physically (or logically) meets. This is not the exam calendar — it's "Tues/Thurs 9:00–10:50" style facts.

Who uses this later
  • First Day Handout — fills in class days and class time on the printed handout
  • Pearson — default homework due time (class start for in-person; 11:59 PM for online)
  • Next setup step — suggests which My Calendar tab to attach (Tue/Thu → "Tuesday/Thursday")
For each new section
Attach this D2L section to a calendar workbook tab

This is the step people find confusing. Here's what it means in practice:

In My Calendar, each course template (like M1314 Fall) is a workbook with multiple tabs for different sections — "Monday/Wednesday", "Tuesday/Thursday", "Online", and so on. Each tab is a full semester grid with exam dates, quiz dates, drop date, and first day of class.

Example: Your D2L section "MATH-1314 4201 Fall" meets Tue/Thu. You attach it to the M1314 Fall → Tuesday/Thursday tab in My Calendar. From now on, when you pick that D2L section in Pearson or First Day Handout, the app reads exam and quiz dates from that specific tab — not from a guess based on the course title.

The app may suggest a tab based on your schedule from the previous step. You confirm or pick a different one. You can skip and fix it later from the Browser tab (Course Schedules area) without rerunning the whole wizard.

What you're deciding: "This D2L shell and that calendar grid tab are the same class."

Who needs this attachment
  • Pearson — exam dates (and exam windows for online) to build unit due dates
  • First Day Handout — the Important Dates table (quizzes + exams) and drop date
  • Manage Dates — knows which assignment template to pre-select when pushing dates into D2L

If this link is missing, Pearson and First Day Handout will stop and tell you to attach a calendar tab — they no longer guess from the course name.

Optional
Rename course folders

Makes the folder name on your drive match what you call the course. Purely for your own organization — nothing in the app breaks if you skip this.

Gradebook setup
Set up gradebook files now?

The wizard asks whether to download student rosters right away.

  • Yes — you pick a parent folder (often your Google Drive "Rosters" area). The app creates one folder per course and downloads a roster CSV from D2L for each.
  • Not now — course folders only. You can export rosters later from the Gradebook tab.

What you're deciding: where student lists live and whether to pull them today. This has nothing to do with exam dates or Pearson — it's the gradebook side of the house.

What ends up in each course folder
  • Roster CSV — student names, emails, org IDs (downloaded from D2L)
  • Later: grade backups, Assignment Assistant working file, session files — all created as you use those tabs
Who uses the roster file
  • Gradebook — owns it; refreshes when students add/drop
  • Assignment Assistant — builds its working gradebook from the roster
  • Makeup Exam — student picker list
  • Not Pearson, First Day Handout, or My Calendar — they never touch the roster
Later, from the Gradebook tab
Pull grades from D2L

When you pull grades, dated backup CSVs are saved inside each course's gradebook folder. Only the Gradebook reads these — for history, restore, and push-back to D2L.

The two My Calendar tabs — and why both matter

Step 3 above attaches your D2L section to the calendar grid tab. But My Calendar also has a separate assignment calendar — and Manage Dates uses that one, not the grid.

Calendar grid tab

What it looks like: the visual semester calendar — Exam 1, Exam 2, quizzes, drop date, first day.

What it holds: dates for big milestones. Not individual homework due times.

Attached in Setup step 3. Used by Pearson and First Day Handout.

Assignment calendar tab

What it looks like: a spreadsheet — one row per D2L assignment with start date, due date, start time, due time.

What it holds: the full due-date schedule you push into D2L (homework, discussions, quizzes, etc.).

Set up in My Calendar (you assign which assignment calendar goes with which section). Used by Manage Dates when you apply a schedule to D2L.

The assignment tab and the grid tab are linked to the same section — same course, same term, same meeting pattern — but they answer different questions. The grid says "when is Exam 2?" The assignment tab says "Homework 3.4 is due Tuesday at 11:59 PM."

What each Macro App tab needs from setup

First Day Handout

Needs: calendar grid tab attached + class schedule

From the calendar grid tab: quiz and exam dates for the Important Dates section, drop date, how many exams, final exam timing.
From the class schedule (step 2): "Tues/Thurs" and "9:00–10:50" on the handout — those come from what you entered about meeting days and times, not from the calendar grid.
Does not use the roster or assignment calendar.

Pearson

Needs: calendar grid tab attached

Reads exam dates (and online exam windows) from the linked grid tab to place units and set homework due dates. Uses class schedule for default due times. Will not run without the calendar attachment from setup.

Manage Dates (D2L)

Needs: calendar attachment + assignment calendar in My Calendar

Pre-selects the right template when you open it. Builds a CSV from the assignment calendar (start/due dates and times per assignment) and applies it on D2L's Change Due Dates page. Exam dates on the grid tab are not what gets pushed here.

Gradebook

Needs: course in your list + roster CSV (or grade backup)

Uses the course list from setup and the roster file from the gradebook folder. Does not care about calendar tabs. Pulls grade backups into the same folder.

Assignment Assistant

Needs: roster CSV

Opens a working copy of the gradebook built from the roster. Stays in sync when Gradebook refreshes the roster after add/drop.

Makeup Exam

Needs: roster CSV

Student list for scheduling makeup exams. Nothing from the calendar setup.

How it flows — one picture

Setup: pick courses → every tab knows which sections exist
Setup: class schedule → handout days/times, Pearson due-time defaults, calendar tab suggestion
Setup: attach calendar grid tab → Pearson exam dates, handout Important Dates, Manage Dates template picker
My Calendar: assignment calendar → Manage Dates pushes per-assignment due dates into D2L
Setup: roster export → Gradebook, Assignment Assistant, Makeup Exam
