What Is Always-On

Orientation
First move - find the doc
Tells agents to start with agent docs/INDEX.md before grepping the tree.
Why it stays: without this, the whole keyword-router system is optional.
Screen safety
Never put anything on Chase's screen without asking
No surprise GUI launches, windows, browser opens, display changes, overlays, or UI smoke tests.
Why it stays: a stolen focus or display change can leave Chase unable to undo it.
Input safety
No keyboard-driven handoffs
Do not send Chase into terminal prompts, arrow-key menus, or type-to-filter boxes as the next step.
Why it stays: it prevents workflows that are technically correct but physically unusable.
Conversation
Ask before assuming
Ask one focused question when scope, wording, or approach is genuinely ambiguous.
Why it stays: Chase uses speech-to-text, and misheard terms can send an agent into the wrong app.
Shell
Windows PowerShell 5.x
&&, ||, and bare curl are wrong defaults here.
Why it stays: four lines prevent routine command failures in almost every session.
Code shape
The most violated rules
File-size cap, entry-file orchestration, preserve behavior, grep before new mechanisms, no backdrop-dismiss modals, plus React extraction/service-layer reminders.
Why it stays: these are broad failure modes that create expensive cleanup when missed.
Launchers
Never a visible console
Launcher surfaces must not spawn detached visible cmd.exe windows.
Why it stays: launchers are how Chase opens apps, and a visible console steals focus and can kill the app when closed.
Git
Pull at start, push at end
Scan sibling repos, fetch, fast-forward clean-behind repos, stop on dirty-and-ahead collisions, commit/push only when asked or at end-of-session.
Why it stays: Programs is many sibling repos, not a monorepo, so sync must be agent-driven.
Bookkeeping
Session scorecard
After each completed deliverable, bump the running scorecard file through the script.
Why it stays: it preserves work counts through summarization and long sessions.
Closeout
End-of-session protocol
Routes wrap-up phrases to the detailed closeout doc; state/resume phrases read the latest session log instead.
Why it stays: the trigger must be noticed, but the full procedure does not belong in startup context.
Memory
Capturing a lesson
"Capture this" means run the capture skill, grep existing coverage, write or update the owner, and index it.
Why it stays: the trigger itself is easy for agents to miss if it is only hidden behind a lookup doc.
Rule placement
Capture ladder
One table names the five rungs: structure, lint/test, recipe or app keyword row, always-on rule, on-demand doc.
Why it stays: it keeps new rules from landing in the wrong layer.
Frozen work
Calendar 2.0
No scans, edits, or git sync unless Chase explicitly names the frozen app.
Why it stays: by the time an agent thinks to look this up, it may already have scanned or touched the folder.
Clickable pages
HTML delivery
When Chase asks for HTML, return only a clickable 127.0.0.1:8765 link, never a file path or opener script.
Why it stays: the wrong kind of link is unusable from chat.
Search
Searching this tree
Use content search that respects ignores; scope filename search; preserve /.ignore.
Why it stays: bad search results lead agents to edit build copies or rebuild code that already exists.

What Is Deliberately Not In The Head File

Long procedures. End-of-session steps, HTML serving details, git edge cases, and screen-safety incidents live in detail docs.

Individual recipes. Drag, dwell, modal, canvas, animation, and overlay patterns belong in recipes/INDEX.md and one recipe file.

App-specific knowledge. Pearson, gradebook, Launcher Panel, Macro App, and other local systems route through the app's own AGENTS.md.

Repeated values. Timings, thresholds, and sizes should live in one owner. Other files point at that owner.

Historical explanation. Why .mdc went away and how the instruction layer evolved lives in HOW_TO_INTERACT_WITH_AI.md and the visual architecture pages.

One-off visuals. Temporary diagrams belong in agent docs/scratch/, not the maintained instruction-layer HTML collection.
