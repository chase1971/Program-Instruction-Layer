What to say

Say thisGit?What happens
Wrap up the session No Log this chat in the right SESSIONS.md. Required line: Repos touched: (folder paths). Other agents can keep working.
Put on GitHub · end of session protocol Yes Commit + push every dirty repo in your Pull list (see registry). End of night — cloud matches disk.
Pull from GitHub Yes Session-guided sync + only repos marked Pull in the registry. Fetch each; pull/push only where different. Skip repos are silent.
Pull everything Yes Full sweep of the Pull list (not every folder on disk — not deprecated/games you skipped).
Pull macro app · pull portal · … Yes That bundle only (portal always includes student-portal + student-session-kit).

Pull from GitHub — agent steps

  1. Load agent docs/sync-pull-registry.json — only pull: true repos unless you named one explicitly.
  2. Pull Programs root if behind (session logs + registry file on GitHub).
  3. Read new SESSIONS.md entries since this machine’s last date; union Repos touched: from those entries.
  4. Fetch → compare → pull/push/stash only where needed.
  5. If something important is behind but missing from logs, sync it anyway (one-line mention only if blocked).

Unpushed wrap-ups are not on GitHub yet — laptop cannot see tonight’s log until put on GitHub.
