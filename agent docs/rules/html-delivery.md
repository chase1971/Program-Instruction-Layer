## Workflow

1. Self-contained `.html` under **`docs/`** (inline CSS).
2. `node scripts/serve-programs-docs.js` if port 8765 not up (background OK).
3. Verify: `Invoke-WebRequest http://127.0.0.1:8765/<file>.html -UseBasicParsing`
4. Reply with **one markdown link:** `http://127.0.0.1:8765/<file>.html`
5. Do **not** open the browser yourself (rule 05). No `.bat` openers.
