**Not always-on** — the always-on half is only the *never* (no `C:\`, no `file:///`, no `.bat`),

matters once you've decided to build a page, and by then you know to read this.

## Where files actually go

**There is no `Programs/docs/` folder.** It has never existed. Earlier versions of this doc and
of `AGENTS.md` both said to write there — corrected 2026-08-05.

| Kind of page | Folder | Maintained? |
|---|---|---|
| **Explains how the instruction layer is organized** | `agent docs/instructional-layer-htmls/` | **Yes** — update it when the structure changes |
| **One-off "show me what this does"** | `agent docs/scratch/` | **No** — add a dated banner; assume it goes stale |
| **Teaching material** — exam maps, review maps, handouts | `School Scrips/School documents/` | Its own repo |
| Generated by a script | wherever the script writes | Never edit by hand |

**The front door is `agent docs/index.html`**, served at `http://127.0.0.1:8765/`. Add a card
there for anything durable, and give each page a `← All pages` link back.

`scripts/serve-programs-docs.js` serves **three** roots, checked in this order:
`School Scrips/School documents/` → `Programs/docs/` (absent) → `agent docs/`.
School documents wins ties — that is why the live `exam2-review-map.html` is the one there,
not the 1 KB stub in `agent docs/`. **Subfolders work**, so
`/instructional-layer-htmls/foo.html` resolves.

## Trigger phrases

| Chase might say | Do this |
|---|---|
| "link it" / "give me a link" / "make me an HTML page I can click" | Build → serve → http link |
| "HTML" + report / map / comparison / infographic | Same |
| "clickable" / "open from here" / "open from chat" | Same |

**Never** paste `C:\Users\...`, `file:///`, or a bare relative path as the only link.

## Workflow

1. Self-contained `.html` (inline CSS, no external fetches) in the folder from the table above.
2. `node scripts/serve-programs-docs.js` if port 8765 isn't up (background OK, no browser).
3. Verify: `Invoke-WebRequest http://127.0.0.1:8765/<file>.html -UseBasicParsing` — expect 200.
4. Reply with **one markdown link**: `http://127.0.0.1:8765/<file>.html`.
5. Do **not** open the browser yourself — root `AGENTS.md` § Never put anything on Chase's screen.
6. Dwell-friendly: big click targets, whole cards clickable, no hover-only affordances.

## Non-negotiables

| Rule | Bug it prevents |
|------|-----------------|
| Never `C:\...` / `file:///` in chat | `%5C` broken link |
| Never `.bat` delivery | Chase won't browse to double-click |
| Port **8765** + `serve-programs-docs.js` | Broken bookmarkable URLs |
