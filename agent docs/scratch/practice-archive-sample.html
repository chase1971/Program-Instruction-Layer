Who is who?

Students sign in with a code (e.g. CHASE1). Supabase stores an internal UUID on every attempt row. The Teacher Console should show Instructor · CHASE1 or Last, First — not a raw UUID. If you see e5532e6b…, that was a label bug (fixed); hit Refresh responses after restarting Macro App.
