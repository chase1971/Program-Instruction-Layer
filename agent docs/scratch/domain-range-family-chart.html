Domain & range cheat sheet

Four families in the forms you graph from — vertex form for quadratics and square roots, graphing form for rationals. Interval notation at the end of each block.

Linear Domain: (−∞, ∞) Range: (−∞, ∞)
Quadratic Domain: (−∞, ∞) Range: depends on a, k
Square root Domain: radicand ≥ 0 Range: depends on a, k
Rational Domain: x ≠ c Range: y ≠ d

Linear

f(x) = mx + b

Domain

  1. No denominator, even root, or log — input can be any real number.

Interval notation(−∞, ∞)

Range

  1. Unless the line is horizontal (m = 0), outputs hit every real y.
  2. If m = 0, the range is the single value y = b.

Typical (non-horizontal)(−∞, ∞)

Horizontal line only{b}

Quadratic (vertex form)

f(x) = a(x − h)2 + k

Domain

  1. Polynomial — no input restrictions.

Interval notation(−∞, ∞)

Range

  1. Vertex is (h, k). That k is the smallest or largest output.
  2. Use the sign of a (opens up or down).
If a > 0 (opens up): minimum y = k.

[k, ∞)

If a < 0 (opens down): maximum y = k.

(−∞, k]

Square root (graphing form)

f(x) = a√(x − h) + k

Domain

  1. Whatever is under the root must be ≥ 0.
  2. Set x − h ≥ 0 and solve for x.

Inequality → intervalx ≥ h  ⟹  [h, ∞)

Range

  1. Endpoint of the graph is (h, k) — same idea as the quadratic vertex.
  2. Sign of a tells you whether outputs grow up or down from k.
If a > 0 ( rises to the right ):

[k, ∞)

If a < 0 ( falls to the right ):

(−∞, k]

Rational (graphing form)

f(x) = a / (x − c) + d

Domain

  1. Denominator cannot be zero.
  2. Set x − c ≠ 0 ⟹ x ≠ c.

Interval notation(−∞, c) ∪ (c, ∞)

Range

  1. Horizontal asymptote y = d is approached but never reached.
  2. So y can be anything except d.

Interval notation(−∞, d) ∪ (d, ∞)

Animation hook: quadratics and square roots share the same range pattern — read a, anchor at k, then pick [k, ∞) vs (−∞, k]. Rationals flip the idea: two values (c and d) are removed from domain and range.
