Dynamic animation demo: standard form to y = mx + b

Scratch demo, 2026-10-23. Type any whole numbers for A, B and C and the animation is built from them on the spot. This runs in the browser; it is not a Manim video, and it is not wired into any app.
Try:

How this works

There is no video file. One function, plan(A, B, C), looks at the numbers and decides which steps are needed and what each row says. A second function, render(stage), draws the board for that step. Change a number and the whole animation is rebuilt, including skipping steps that do not apply (no x term when A is 0, nothing to divide when B is 1) and reducing the fractions.
