Display settings — 5 redesign concepts

Macro App Settings → Display tab. Generated 2026-09-24. Pick a direction (or mix) for implementation.

One-off mockups — may not match live app pixel-perfect. Recommended lean: C + B (Portal sidebar tab + preset chips, no sliders).

A — Split sub-tabs

App & Browser | Portal preview pills inside Display. Location dropdown, − / % / + steppers, no sliders.

B — Preset chips + collapsed portal

75 / 85 / 95 / 99 / Fit chips. “Same scale for browser” toggle. Portal in accordion.

C — Fourth sidebar tab: Portal

Display · Portal · Computer · Logins. Display = location + preview + steppers only.

D — Two-column compact

Location list left, S/M/L/XL/Fit right. Link browser zoom checkbox. Portal via link → sub-dialog.

E — Card picker (dwell-friendly)

Three big cards: Comfortable / Default / Fill window. Browser chips below. Portal gear → small overlay.
