How to read waits
  • poll — waits until D2L is ready, then goes to the next step immediately. Max is a ceiling, not a delay.
  • fixed — always sleeps the full duration even if the page is already ready (real waste candidate).
  • navigate — full page load; ends when DOM event fires, then continues.
  • skip — no wait when condition already met (e.g. already on Enter Grades).
