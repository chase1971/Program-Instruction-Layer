Part 1

Step 1

This tutorial is going to teach you how to use the Gauss-Jordan method to put the augmented matrix in row-reduced echelon form.

Step 2

Our goal is to transform our current matrix into row-reduced echelon form.

Step 3

First, we need to start here. Click on the indicated cell.

Step 4

The first number here needs to become a 1. There are two ways you could do that: Row Swap or Row Scaling.

Step 5

Press the Row Swap button to see what happens.

Step 6

Row Swap is only useful if the number underneath is a 1. Since this was a -2, the row swap doesn't help us any.

Step 7

Instead, let's try Row Scaling. Click on the Row Scaling button.

Step 8

Row scaling involves multiplying a number to each of the numbers in the row.

Step 9

In this case, because we want to get a 1 in this position, we need to multiply it by the reciprocal.

Step 10

The reciprocal of 4 is 1/4. We write the transformation notation to show we are multiplying Row 1 by 1/4.

Step 11

Watch how each number in Row 1 gets multiplied by 1/4.

Step 12

Great! We have now successfully converted the first pivot position to a 1, which is now our new Row 1.

Step 13

Write this new matrix down on the paper for Part A.

Step 14

Finished! That's the end of Part 1.

Click the button to continue.

Part 2

Step 1

We have successfully created a 1 in the first pivot position. Now our goal is to get a 0 in the position below it.

Step 2

In order to make the -2 a 0, we will need to use a row replacement. Press the Row Replacement button.

Step 3

Row replacement multiplies one row by a number, then adds that result to another row. The second row is replaced by that sum.

Step 4

In order to get a zero, multiply the pivot by the opposite of the number you want to become zero, in this case, 2.

Step 5

Then we will add that row to Row 2. This result will replace the values in row 2. Please use the calculator to do the fraction math if necessary.

Yellow tip on notation: Row Transformation Notation for Row Replacement — Write this down in Part B

Yellow tip on sum: SUM — Write this out in Part C

Step 6

The matrix has been updated! Row 2 now contains the new values. Notice that the -2 has been eliminated and replaced with 0.

Step 7

Write the new matrix in Part D.

Step 8

The first column is now complete. Let's move on to the second column.
