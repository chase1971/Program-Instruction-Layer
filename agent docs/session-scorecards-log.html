What do these numbers mean? (hover any label on a card too)
  • Your messages: How many messages you sent in this chat. Rough proxy for how long the session ran.
  • Searches: How many times the agent searched the tree (grep, glob, file hunt). High usually means re-exploring instead of using a doc or rule.
  • You corrected me: Times you pushed back: "no", "wrong", "again", "third time". High means the agent drifted or misunderstood.
  • Docs/rules read: Instruction files the agent opened to learn what to do (.md, .mdc, HTML guides). Count of names listed — not files it created.
  • Low confidence counts: The numbers may be wrong because Cursor summarized away the start of this chat — counts are best-guess.
  • Chat was summarized: Cursor compressed older messages to save space. Early reads/searches may be missing from the counts.
  • Agent suggests capturing: The agent's idea for a future rule or doc. Not a list of what you already asked to build unless you did.
